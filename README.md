## 🚀 Projetos em Destaque

### 💰 [boleto-manager](https://github.com/DavidRodriguesDev/boleto-manager)
> Sistema web completo para gestão de cobrança com geração automática de boletos e notificações via WhatsApp e e-mail.

| Stack | Detalhes |
|-------|----------|
| **Frontend** | React 18 + TypeScript + Vite |
| **Backend** | Node.js 18 + Fastify 4 |
| **Banco** | PostgreSQL + Redis |
| **WhatsApp** | Evolution API v2 |
| **E-mail** | Gmail SMTP |

**Principais funcionalidades:**
- 📄 Geração automática de boletos todo dia 1º do mês
- 💬 Lembretes automáticos via WhatsApp 2 dias antes do vencimento
- 📧 Notificações por e-mail com Gmail SMTP
- 📊 Dashboard com estatísticas, gráficos de crescimento e inadimplência
- 👥 CRUD completo de clientes, planos e boletos

### 🛒 [sisweb-vendas-laravel](https://github.com/DavidRodriguesDev/sisweb-vendas-laravel)
> Sistema de gerenciamento de vendas com PDV, controle de estoque e relatórios em PDF.

| Stack | Detalhes |
|-------|----------|
| **Backend** | Laravel 11 + PHP 8.2+ |
| **Frontend** | Tailwind CSS + Alpine.js + Vite |
| **Banco** | PostgreSQL 16 |
| **Infra** | Docker (Nginx + PHP-FPM + Node) |

**Principais funcionalidades:**
- 🏪 PDV com desconto, múltiplas formas de pagamento (PIX, cartão, boleto)
- 📦 Controle de estoque com alertas de estoque mínimo
- 📊 Dashboard com vendas do dia/mês e produtos mais vendidos
- 📄 Relatórios com exportação em PDF
- 🔐 Controle de acesso por papéis (admin / vendedor)
